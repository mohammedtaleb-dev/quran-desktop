# القرآن الكريم — برنامج سطح مكتب لويندوز

![شعار البرنامج](src/img/logo.png)

الإصدار 1.2.0.

مصحف شامي بخط عثمان طه، فيه لفظ الجلالة و«رب» ومشتقاتها بالأحمر. يعمل بدون إنترنت، وهو مبني بـ [Tauri 2](https://tauri.app).

## المحتويات

| المسار | ما فيه |
|---|---|
| `src/` | واجهة البرنامج (HTML/CSS/JS بدون أدوات تجميع) |
| `src/js/meta.js` | بيانات السور والأجزاء والأرباع (مولّدة) |
| `src/data/` | نص الآيات للبحث، والتفسير الميسر، وأماكن الآيات على الصفحات (مولّدة، تُحمَّل عند الحاجة) |
| `tools/logo/` | الشعار الرسمي: النسخة الأصلية 1024 بكسل في `v2/icon-final.png`، ومنها صُنعت أيقونات `src-tauri/icons/` و`src/img/logo.png` (لتجديد الأيقونات: `npx tauri icon tools/logo/v2/icon-final.png`). الأيقونات القديمة في `backup-old-icons/` |
| `src-tauri/` | جزء Rust، والإعدادات، والأيقونات |
| `src-tauri/pages/` | صور صفحات المصحف الـ604 (مستخرجة من ملف PDF) |
| `src-tauri/docs/` | ملخص التجويد: ضع الملف هنا باسم `tajweed.pdf` ثم أعد البناء. يظهر في «المزيد ← ملخص التجويد» ويمكن حفظ نسخة منه |
| `source/` | ملف PDF الأصلي للمصحف |
| `tools/` | سكربتات تجهيز البيانات ومعاينة الواجهة |

## الأوامر

```bash
npm install
```

```bash
npm run pages
```
يستخرج صور الصفحات من ملف PDF إلى `src-tauri/pages/` كما هي، بدون إعادة ضغط.

```bash
npm run meta
```

```bash
node tools/build-text.js
```

```bash
npm run dev
```
يشغّل البرنامج للتطوير.

```bash
npm run build
```
يبني ملف التثبيت لنسخة 64 بت في `src-tauri/target/release/bundle/nsis/`. ملفّا الإصدار الحالي محفوظان في مجلد `ملفات التثبيت/`. ومجلد `src-tauri/target` يمكن حذفه بعد البناء لتوفير المساحة، ويُصنع من جديد مع البناء التالي.

```bash
npx tauri build --target i686-pc-windows-msvc
```
يبني ملف التثبيت لنسخة 32 بت للأجهزة القديمة في `src-tauri/target/i686-pc-windows-msvc/release/bundle/nsis/`. يحتاج مرة واحدة: `rustup target add i686-pc-windows-msvc`.

> بعد تغيير الأيقونة شغّل `touch src-tauri/build.rs` قبل البناء، وإلا تبقى الأيقونة القديمة داخل البرنامج.

```bash
npm run preview
```
يعرض الواجهة في المتصفح على `http://localhost:5180` لفحص سريع.

## اختصارات لوحة المفاتيح

- **← / PageDown / مسافة:** الصفحة التالية
- **→ / PageUp:** الصفحة السابقة
- **Home / End:** أول المصحف وآخره
- **Ctrl+F:** البحث
- **F11:** ملء الشاشة. البرنامج يفتح مكبّراً، وF11 أو Esc يرجعه
- **Esc:** إلغاء تحديد الآية، أو إغلاق النوافذ، أو الخروج من ملء الشاشة، أو إظهار وإخفاء الأشرطة
- **عجلة الماوس:** تقليب الصفحات. في وضع «تكبير للقراءة» تمرّر الصفحة فقط، وتتوقف عند آخرها ولا تقلّب. التقليب بالأسهم على الجانبين أو ← →
- **↓ / ↑:** التمرير في وضع «تكبير للقراءة»
- **النقر على الصفحة:** إظهار وإخفاء الأشرطة
- **زر الفأرة الأيمن أو النقر المزدوج على آية:** تحديد الآية، ثم «نسخ الآية» أو «تفسير الآية». النقر المزدوج لا يُظهر الأشرطة ولا يخفيها، فيبقى النسخ ممكناً حتى لآيات أسفل الصفحة
- **أول تشغيل:** تظهر إرشادات قصيرة مرة واحدة، وتجدها بعد ذلك في «المزيد ← طريقة الاستخدام»
- **Ctrl+C:** نسخ الآية المحددة

## الأداء والأجهزة الضعيفة

- **خفيف بطبيعته، بدون إعدادات:** الزجاج مرسوم بضبابية خفيفة يتحملها أي كرت شاشة. وعلى الأجهزة الضعيفة جداً (2 جيجا أو معالج ثنائي النواة) يُرسم تلقائياً بنفس الشكل لكن بدون ضبابية حية، والمستخدم ما يحتاج يغيّر أي شيء.
- **بدون إنترنت:** محرك العرض (WebView2) يعمل بإعدادات توقف خدماته الخلفية، فالبرنامج لا يتصل بالإنترنت أبداً.
- **التحميل عند الحاجة:** نص الآيات والتفسير وأماكن الآيات تُحمَّل فقط عند استخدامها.
- **تقليب سريع:** كل صفحة تُقرأ من القرص مرة واحدة وتبقى في الذاكرة (آخر 40 صفحة). تُحمَّل الصفحات المطلوبة أولاً ثم التالية في اتجاه القراءة، وتُلغى طلبات الصفحات التي تجاوزها القارئ، فالضغط السريع على الأسهم لا يكدّس طلبات.
- **الأسهم:** تقلّب الصفحة لحظة نزول زر الفأرة، ولها مساحة ضغط أكبر من الدائرة الظاهرة.

## أماكن الآيات على الصفحات

```bash
node tools/detect-ayahs.js
```
يحدد مكان كل آية على صور الصفحات الـ604، ويكتب النتيجة في `src/data/ayahs.js`. هذا الملف هو اللي يستخدمه البرنامج لتظليل نتيجة البحث ولتحديد آية واحدة ونسخها.

طريقة العمل: كل صفحة تنتهي بنهاية آية، فعدد علامات نهاية الآيات في الصفحة يساوي عدد آياتها. والعلامات تُكتشف بمطابقة شكلها مع قالبين مأخوذين من صفحتي 249 و304.

للفحص بالعين، شغّل الأمر مع أرقام صفحات ومتغير `OVERLAY=<مجلد>`، فيرسم مناطق الآيات ملوّنة فوق الصفحات:

```bash
OVERLAY=./overlay node tools/detect-ayahs.js 1 249 604
```
